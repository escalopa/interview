# Toptal

Coding problems from the Toptal interview, solved in Go.

- [OCR match](ocr-match) — can two OCR strings with unknown-char counts match?
- [Vacation weeks](vacation-weeks) — full weeks from the first Monday to the last Sunday.
- [Valid clock times](clock-times) — distinct `HH:MM` times from four digits.

Run all tests:

```bash
cd toptal && go test ./...
```
